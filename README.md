# drive-range 自驾可达范围

选起点 + 开车时长,在高德地图上画出能到达的范围(等时圈),可叠加 1h/2h/3h 多圈,用于挑自驾游目的地。

## 原理
高德没有官方等时圈接口。本项目沿起点周围 36 个方向、每方向 16 个采样点,调用高德「距离测量」(`/v3/distance`,驾车)取行驶时间,每个方向找出刚好超时的位置并插值,连成多边形。每次查询约 6 次高德请求(576 点 / 100 点每批)。

局限:采样近似,道路稀疏、跨江跨海或山区边缘会有偏差;按"首个超时点"截断,绕路后又能到的远处不计入。

## 部署(Vercel)
1. 高德控制台创建两个 Key:**Web服务** 和 **Web端(JS API)**(后者会得到安全密钥,并建议绑定域名白名单)。
2. Vercel 导入本仓库,配置环境变量:`AMAP_WEB_KEY`、`AMAP_JS_KEY`、`AMAP_JS_SECRET`。
3. 部署即可。无构建步骤:`public/` 为静态页,`api/` 为 Serverless 函数。

本地测试算法:`node test.js`。
